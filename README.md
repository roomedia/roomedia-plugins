# roomedia's Claude Code Plugins

A curated collection of Claude Code plugins by [roomedia](https://github.com/roomedia).

## Install

Add this marketplace:

```
/plugin marketplace add https://github.com/roomedia/roomedia-plugins.git
```

Then install any plugin:

```
/plugin install code-to-spec
/plugin install thank-you
/plugin install absorb-into-commits
/plugin install gksdud
```

## Plugins

| Plugin | Description |
|---|---|
| [code-to-spec](https://github.com/roomedia/code-to-spec) | Reverse-engineer source code into implementation-ready spec documents |
| [thank-you](https://github.com/roomedia/thank-you) | Automatically appends motivational phrases to every prompt |
| [absorb-into-commits](https://github.com/roomedia/absorb-into-commits) | Absorb changes into earlier commits via interactive rebase |
| [gksdud](https://github.com/roomedia/gksdud) | Korean-English keyboard layout converter (한영 변환) |
